SOBRE O PROJETO

Ideias que conectam

O Conecta Jovem é uma experiência web criada para explorar temas presentes no cotidiano dos estudantes: cultura, criatividade e descobertas.

Missão

Valorizar intereses e estimular a curiosidade dos jovens.

Tecnologias

HTML para estruturas, CSS para apresentação e JavaScript para interações.

Recursos

Menu responsivo, filtros, mosaico e modal com navegação.
